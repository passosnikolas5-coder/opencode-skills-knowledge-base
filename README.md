## 📖 Documentação

### Estrutura de Cada Skill

Cada skill é documentada com **7 seções obrigatórias**:

| # | Seção | Descrição |
|---|-------|-----------|
| 1 | **Exemplos Práticos** | 2-3 exemplos de código prontos |
| 2 | **Casos de Uso Avançados** | Projetos reais e cenários complexos |
| 3 | **Integração com Outras Skills** | Skills complementares e sinergias |
| 4 | **Padrões e Anti-padrões** | O que fazer e o que evitar |
| 5 | **Dicas de Performance** | Otimizações importantes |
| 6 | **Comandos Úteis** | Snippets bash/código prontos |
| 7 | **Referências** | Links para documentação oficial |

### Exemplo de Documentação

```markdown
## 1. react-patterns

**Descrição:** Padrões modernos para React incluindo hooks, context e composição.

**Quando usar:**
- Componentes com lógica complexa
- Estado compartilhado entre componentes
- Otimização de performance

**Exemplos práticos:**
```jsx
// Hook personalizado
function useLocalStorage(key, initialValue) {
  const [storedValue, setStoredValue] = useState(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch (error) {
      return initialValue;
    }
  });

  const setValue = value => {
    try {
      setStoredValue(value);
      window.localStorage.setItem(key, JSON.stringify(value));
    } catch (error) {
      console.error(error);
    }
  };

  return [storedValue, setValue];
}
```

**Casos de uso avançados:**
- Dashboard com múltiplos widgets
- Sistema de autenticação
- Aplicativo offline-first

**Integração com outras skills:**
- `zustand-store-ts`: Gerenciamento de estado
- `nextjs-best-practices`: Framework React
- `frontend-design`: Design visual

**Padrões e anti-padrões:**
✅ Usar hooks personalizados para lógica reutilizável
❌ Evitar props drilling excessivo

**Dicas de performance:**
- Use React.memo para componentes puros
- Implemente lazy loading para rotas
- Otimize re-renderizações com useCallback

**Referências:**
- [React Docs](https://react.dev/)
- [React Patterns](https://reactpatterns.com/)
```
