## 🎮 Sobre o Jogo

**Egg Empire** é um jogo onde jogadores:
1. 🥚 Coletam ovos em um mapa dinâmico
2. 🏰 Constroem bases para proteger seus ovos
3. 🗡️ Roubam ovos de outros jogadores
4. 📈 Progressionam com upgrades e desbloqueios
5. 🏆 Competem pelo ranking de impérios

---

## 🎯 Diferenciais

- **Sistema de Base Construível** - Construa e defenda sua base
- **Stealth Real** - Invisibilidade, disfarces, armadilhas
- **Economia Dinâmica** - Preços baseados em oferta/demanda
- **Eventos Globais** - Bônus de ovos raros em horários específicos
- **12+ Ferramentas de IA** - Desenvolvimento assistido por inteligência artificial

```

│   │   ├── BaseBuildingSystem.lua    # Sistema de construção
│   │   └── EggEmpire_Server.lua      # Script principal
│   ├── ReplicatedStorage/            # RemoteEvents (criados auto)
│   ├── StarterGui/                   # UI (criada pelo script)
│   ├── StarterPlayerScripts/
│   │   └── ClientController.lua      # Script do cliente

```

## 🚀 Como Usar

### 1. Ler o Game Design
```
Abra docs/GAME_DESIGN.md para entender o jogo completo
```

### 2. Seguir o Setup
```
Abra docs/SWP/SETUP.md para configurar e publicar
```

### 3. Importar Scripts
```
Copie os scripts de src/ para o Roblox Studio
```

### 4. Testar
```
Pressione F5 no Studio para testar
```

### 5. Publicar
```
File → Publish to Roblox
```
