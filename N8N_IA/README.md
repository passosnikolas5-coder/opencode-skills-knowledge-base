## 🎯 Projetos Documentados

### 1. 📊 Assistente Pessoal Automatizada
Dashboard completo de produtividade com IA.

**Funcionalidades:**
- Leitura de dados em planilhas
- Organização de e-mails, tarefas e reuniões
- Integração com agente de IA
- Resposta via Webhook
- Dashboard de produtividade

**Fluxos Auxiliares:**
- API Dashboard
- Leitor de Reuniões
- Monitor de E-mails
- Secretária IA
- Extrator de Tarefas

---

### 2. 📧 Agente de Resposta a E-mails
Resposta automática interpretando conteúdo com IA.

**Funcionalidades:**
- Disparo por Gmail Trigger
- Análise da mensagem recebida
- Uso de agente de IA
- Memória simples para contexto
- Resposta automática por e-mail

---

### 3. 💰 Agente Financeiro com Subagentes
Atendimento financeiro via Telegram com transcrição de áudio.

**Funcionalidades:**
- Atendimento via Telegram
- Transcrição de áudio
- Agente principal com IA
- Subagentes especializados
- Respostas personalizadas
- Encaminhamento para suporte ou reunião

---

### 4. 🔄 Agente de Reembolso
Análise inteligente de solicitações de reembolso.

**Funcionalidades:**
- Recebimento de solicitação via Webhook
- Consulta de dados em planilha
- Classificação do cliente (bom, comum, problemático)
- Resposta automática ao cliente
- Encaminhamento para equipe quando necessário

---

### 5. 📄 Automação de Notas Fiscais
Processamento completo de documentos fiscais.

**Funcionalidades:**
- Recebimento de notas fiscais por e-mail
- Análise de documentos com IA
- Separação entre documentos pessoais e corporativos
- Upload e organização no Google Drive
- Registro das informações em Google Sheets
- Tratamento de múltiplos anexos
