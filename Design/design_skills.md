## 1. DESIGN CATEGORY (17 skills)

### 1.1 3d-web-experience
- **Descrição:** Expertise em construir experiências 3D para web - Three.js, React Three Fiber, Spline, WebGL e cenas 3D interativas.
- **Quando usar:** Quando precisar criar experiências imersivas 3D, configuradores de produtos, portfólios 3D ou sites com profundidade.
- **Exemplo:** Criar um configurador de produto 3D onde o usuário pode rotacionar e personalizar um modelo de smartphone.

### 1.2 accessibility-compliance-accessibility-audit
- **Descrição:** Especialista em acessibilidade focado em conformidade WCAG, design inclusivo e compatibilidade com tecnologias assistivas.
- **Quando usar:** Para auditorias de acessibilidade, identificação de barreiras e orientação de remediação em interfaces web.
- **Exemplo:** Realizar auditoria completa de acessibilidade em um e-commerce para garantir conformidade com WCAG 2.1 AA.

### 1.3 antigravity-design-expert
- **Descrição:** Habilidade de UI/UX engineering para construir interfaces web altamente interativas, espaciais, sem peso e baseadas em glassmorphism usando GSAP e CSS 3D.
- **Quando usar:** Para criar interfaces com efeitos de flutuação, glassmorphism e animações espaciais sofisticadas.
- **Exemplo:** Desenvolver landing page com cards flutuantes e efeitos de vidro fosco com animações GSAP.

### 1.4 canva-automation
- **Descrição:** Automação de tarefas Canva via Rube MCP (Composio): designs, exports, pastas, brand templates, autofill.
- **Quando usar:** Para automatizar criação de designs, exports em massa e gerenciamento de templates de marca no Canva.
- **Exemplo:** Gerar automaticamente 50 posts para redes sociais usando templates de marca pré-definidos.

### 1.5 design-md
- **Descrição:** Analisa projetos Stitch e sintetiza um sistema de design semântico em arquivos DESIGN.md.
- **Quando usar:** Para documentar e sintetizar sistemas de design a partir de projetos existentes.
- **Exemplo:** Analisar um projeto web existente e gerar documentação completa do sistema de design utilizado.

### 1.6 design-orchestration
- **Descrição:** Orquestra fluxos de trabalho de design direcionando trabalho por brainstorming, revisão multi-agente e prontidão de execução na ordem correta.
- **Quando usar:** Para coordenar projetos de design complexos com múltiplos agentes e fases de revisão.
- **Exemplo:** Gerenciar ciclo completo de redesign de produto desde brainstorming até implementação final.

### 1.7 design-spells
- **Descrição:** Micro-interações curadas e detalhes de design que adicionam "magia" e personalidade a sites e apps.
- **Quando usar:** Para adicionar detalhes de design sofisticados e micro-interações que tornam interfaces maisengajadoras.
- **Exemplo:** Implementar animações de hover em botões que criam efeitos de partículas ou mudanças de cor suaves.

### 1.8 figma-automation
- **Descrição:** Automação de tarefas Figma via Rube MCP (Composio): arquivos, componentes, design tokens, comments, exports.
- **Quando usar:** Para automatizar gerenciamento de arquivos Figma, sincronização de design tokens e exports.
- **Exemplo:** Sincronizar automaticamente design tokens do Figma para o código de produção.

### 1.9 rayden-use
- **Descrição:** Construir e manter componentes e telas Rayden UI no Figma via Figma MCP com aplicação completa de design tokens.
- **Quando usar:** Para trabalhar com componentes Rayden UI no Figma e garantir consistência de design tokens.
- **Exemplo:** Criar biblioteca de componentes Rayden UI no Figma com tokens de cor, tipografia e espaçamento.

### 1.10 stitch-ui-design
- **Descrição:** Orientação especializada para criar prompts eficazes no Google Stitch, ferramenta de design de UI com IA do Google Labs.
- **Quando usar:** Para usar o Google Stitch para gerar designs de UI de alta qualidade para web e mobile.
- **Exemplo:** Criar prompt detalhado no Stitch para gerar design de dashboard de analytics responsivo.

### 1.11 theme-factory
- **Descrição:** Coleção curada de temas profissionais de fontes e cores, cada um com paletas e combinações de fontes selecionadas.
- **Quando usar:** Para aplicar temas profissionais pré-definidos a interfaces, selecionando paletas de cores e combinações de tipografia.
- **Exemplo:** Aplicar tema "Corporate Blue" com paleta azul profissional e fontes serifadas em site institucional.

### 1.12 ui-visual-validator
- **Descrição:** Expert em validação visual rigorosa especializado em testes de UI, conformidade com sistemas de design e verificação de acessibilidade.
- **Quando usar:** Para validar visualmente interfaces, garantir conformidade com sistemas de design e verificar acessibilidade.
- **Exemplo:** Validar se todas as páginas de um site seguem o sistema de design corporativo em termos de cores, tipografia e espaçamento.

### 1.13 uxui-principles
- **Descrição:** Avalia interfaces contra 168 princípios UX/UI baseados em pesquisa, detecta antipatterns e injeta contexto de UX em sessões de codificação IA.
- **Quando usar:** Para avaliar interfaces com base em princípios estabelecidos de UX/UI e identificar problemas de usabilidade.
- **Exemplo:** Auditar formulário de checkout identificando violações de princípios UX como hierarquia visual, feedback e redundância de erros.

### 1.14 vizcom
- **Descrição:** Ferramenta de design de produto com IA para transformar sketches em renders 3D de alta fidelidade.
- **Quando usar:** Para transformar esboços e sketches em renders 3D realistas de produtos.
- **Exemplo:** Converter esboço de cadeira em render 3D fotorrealista para apresentação a clientes.

### 1.15 wcag-audit-patterns
- **Descrição:** Guia abrangente para auditar conteúdo web contra diretrizes WCAG 2.2 com estratégias de remediação acionáveis.
- **Quando usar:** Para conduzir auditorias completas de conformidade WCAG 2.2 com planos de correção específicos.
- **Exemplo:** Realizar auditoria WCAG 2.2 AAA em portal governamental e gerar relatório com correções priorizadas.

### 1.16 web-design-guidelines
- **Descrição:** Revisa arquivos para conformidade com Diretrizes de Interface Web.
- **Quando usar:** Para garantir que código de interface web siga diretrizes estabelecidas de design e usabilidade.
- **Exemplo:** Revisar componentes React para garantir conformidade com diretrizes de responsividade e acessibilidade.

### 1.17 webflow-automation
- **Descrição:** Automação de Webflow CMS collections, publicação de sites, gerenciamento de páginas, uploads de assets e pedidos de e-commerce via Rube MCP.
- **Quando usar:** Para automatizar gerenciamento de conteúdo, publicação e operações de e-commerce no Webflow.
- **Exemplo:** Sincronizar automaticamente produtos de e-commerce do Webflow com inventário de sistema externo.
