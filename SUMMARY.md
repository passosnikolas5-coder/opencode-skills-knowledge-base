## 🚀 Como Usar

### 1. **Navegação Rápida**
- Abra `README.md` para visão geral
- Use `INDEX.md` para buscar por área de interesse
- Use `Ctrl+F` para busca por palavras-chave

### 2. **Carregar uma Skill**
```bash
skill <nome-da-skill>
```

### 3. **Exemplos de Uso Comum**

#### Para Desenvolvimento Web:
```bash
skill react-best-practices
skill nextjs-best-practices
skill tailwind-patterns
```

#### Para Backend:
```bash
skill api-designer
skill backend-dev-guidelines
skill fastapi-router-py
```

#### Para DevOps:
```bash
skill docker-expert
skill kubernetes-architect
skill terraform-specialist
```

#### Para AI/ML:
```bash
skill langchain
skill hugging-face
skill prompt-engineering
```

#### Para Segurança:
```bash
skill api-security-best-practices
skill backend-security-coder
skill src-hunter
```
