## 🎯 O Que São Skills de IA?

**Skills de IA** são conhecimentos especializados, padrões de código, frameworks e metodologias que permitem a IAs:
1. **Resolver problemas** específicos
2. **Criar soluções** profissionais
3. **Otimizar processos** existentes
4. **Inovar** com novas abordagens
5. **Colaborar** com humanos e outras IAs
